# Antecedente del anfitrión 0.3.1

Copias históricas de la implementación específica de proveedor y sus pruebas, trasladadas fuera del repositorio de la app. No son código de la nueva extensión ni se distribuyen dentro del APK. La versión 0.2.0 usa fuentes en sources/youtube_music.dart y el contrato genérico del anfitrión 0.3.2. Estos archivos documentan el antecedente; requieren la API antigua para ejecutarse.
